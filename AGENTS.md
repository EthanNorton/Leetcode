# AGENTS.md

## Cursor Cloud specific instructions

This is a Python-only learning/practice repository (LeetCode, CMU MSML prep, Deep-ML, RL-book, Supply Chain optimization, SQL). There are no services to run — all files are standalone scripts or Jupyter notebooks.

### Running scripts

- All `.py` files are standalone; run with `python3 <path>`.
- Some scripts in `RL-book/Chapter1_Introduction/` use relative imports (`run_test.py`, `test_01.py`) and must be run from their directory.
- Notebooks can be executed via `jupyter nbconvert --to notebook --execute <path>` or interactively with `jupyter notebook`.

### Dependencies

All required Python packages: `numpy pandas matplotlib scipy pulp sympy seaborn scikit-learn jupyter sqlalchemy ipython-sql`.

No `requirements.txt` or `pyproject.toml` exists in the repo. The update script installs these via pip.

### Linting

Run `flake8 --select=E9,F63,F7,F82` for critical errors. Many LeetCode solution files have pre-existing `F821` (undefined name `List`) and `E999` (syntax errors in incomplete solutions) — these are expected in this learning repository.

### Known pre-existing issues

- `Optimization_Learning_Path/convex_optimization/challenges/week1_foundations/convex_function_checker.py` uses `scipy.misc.derivative` which was removed in SciPy 2.0.
- Several LeetCode solutions are incomplete (syntax errors, missing imports).
- `RL-book/Chapter2_Multi_Armed_Bandits/03_thompson_sampling.py` has a flaky assertion that occasionally fails due to randomness.
- Some Supply Chain notebooks depend on data generated by other notebooks in the same directory.
